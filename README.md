# AISHIFT 파이썬 터미널 게임 모음

파이썬 **기본 문법만**(변수, 조건문, 반복문, 함수, 리스트, 파일 읽고 쓰기) 사용해서 만든 터미널 게임 모음입니다.
모든 게임이 같은 화면 구성(AISHIFT 타이틀 → 게임 안내 → 플레이 → 결과)과 같은 코드 스타일을 가지고 있어서,
**파이썬을 처음 배우는 사람이 코드를 읽으며 공부하기에 좋습니다.**

## 실행 방법

### 준비물

- Python 3 (3.8 이상 권장)
- **Windows** 터미널 (화면을 지울 때 `cls` 명령을 쓰기 때문입니다)
  - macOS / Linux에서는 각 `main.py`의 `os.system("cls")`를 `os.system("clear")`로 바꾸세요.
- 한글과 `■ ★ ♥` 같은 기호가 깨지면 터미널 글꼴/인코딩을 확인하세요. (Windows Terminal 권장)

### 실행

게임 폴더로 들어가서 `main.py`를 실행합니다.

```bash
cd number_baseball
python main.py
```

시작 화면에서 `S`는 시작하기, `Q`는 종료하기입니다. (타자연습은 `R` 랭킹 보기도 있습니다.)

> 타자연습은 랭킹 파일(`ranking.txt`)이 **실행한 위치**에 만들어집니다. 반드시 해당 게임 폴더 안에서 실행하세요.

## 코드 읽는 순서 (학습자용)

모든 게임의 `main.py`는 구역별로 구분선과 주석이 달려 있고, 공통으로 쓰는 화면 함수(`clear`, `ask`, `center`, `show_title`)가 같습니다.

1. **타자연습**부터 읽으며 전체 구조(화면 출력 → 기록 계산 → 랭킹 → 게임 → 메인 반복문)를 익힙니다.
2. **숫자 맞추기**: 가장 단순한 게임. 입력 검사(`check_guess`)와 반복문을 봅니다.
3. **숫자 야구**: 리스트와 문자열을 다루며 판정(`judge`)을 만들어 봅니다.
4. **카드 뒤집기**: 리스트 두 개(`cards`, `matched`)로 게임 상태를 관리하는 방법을 봅니다.

### 도전 과제

- 숫자 맞추기의 범위나 숫자 야구의 자릿수를 바꿔서 난이도 조절하기
- 카드 뒤집기의 문양을 늘려서 판을 키우기 (`SYMBOLS`, `COLS`)
- 적은 시도 기록을 파일에 저장해서 최고 기록 보여 주기
