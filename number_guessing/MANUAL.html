숫자 맞추기 구현 매뉴얼

컴퓨터가 정한 1~100의 숫자를 UP / DOWN 힌트로 맞히는 게임

완성된 프로그램이 어떻게 동작하는지 한눈에 보여 줍니다. 아래 각 단계는 이 순서도의 한 부분을 만드는 과정입니다.

01

타이틀 화면 만들기

필요한 기능
화면 지우기와 입력 칸
  • 화면을 지우는 기능
  • 항상 같은 모양( > )의 입력 칸. 입력한 글자의 앞뒤 공백은 없앤다.
  • 맨 위 설정값: 화면 폭(62), 가로줄, 입력 칸 모양
글자 폭 계산
  • 글자가 화면에서 차지하는 칸 수 계산: 한글 2칸, 영어·숫자·기호 1칸
가운데 정렬 출력
  • 한 줄 가운데 정렬 출력, 여러 줄을 '가장 긴 줄' 기준으로 한꺼번에 가운데 정렬 출력
타이틀 화면 그리기
  • 가로줄, AISHIFT 문자 그림(로고), 부제 숫자 맞추기, 메뉴 안내가 있는 타이틀 화면
메인 메뉴 반복
  • 메뉴 입력(대문자·소문자 모두 인식): S 시작하기, Q 종료하기
  • 프로그램이 계속 반복되며 타이틀로 돌아오고, Q를 눌러야만 끝난다
  • 아직 게임이 없으므로 S는 '준비 중' 문구를 보여 주고 Enter 후 타이틀로 돌아온다

게임 로직 1 — 정답 정하기와 힌트

필요한 기능
정답 정하기
  • 1~100 사이의 숫자 하나를 무작위로 정한다. (한 판이 시작될 때마다 새로, 범위는 설정값)
입력 확인
  • 입력이 올바른지 확인하고, 틀렸다면 이유를 알려 주는 기능
  • 숫자가 아니거나 범위 밖이면 각각 다른 안내 문구
힌트
  • 입력한 숫자와 정답을 비교해 힌트를 만든다: 작으면 UP, 크면 DOWN, 같으면 정답!

게임 로직 2 — 한 판 진행

필요한 기능
시도 횟수와 도전 기록 화면
  • 입력할 때마다 화면을 새로 그린다: 시도 횟수 → 도전 기록 → 입력 안내 → 입력 칸
  • 도전 기록: 입력한 숫자와 힌트가 순서대로 쌓인다. 기록이 없으면 아직 도전 기록이 없습니다.
한 판 반복 (입력 → 힌트 → 기록)
  • 정답을 맞힐 때까지 계속 입력받는다 (시도 횟수 제한 없음)
잘못된 입력 처리와 안내 문구
  • 잘못된 입력은 시도로 세지 않고, 안내 문구를 다음 화면에 한 번만 보여 준다

(도전) 최대 몇 번이면 될까? 자동 계산

필요한 기능
(도전) 최대 N번 자동 계산
  • 안내 화면의 목표 문구에 범위를 절반씩 줄여 가며 맞힐 때 필요한 최대 횟수를 넣는다. 사람이 숫자를 적지 말고 범위에서 계산한다.
결과물 예시 화면
(도전) 최대 N번 자동 계산
안내 화면의 한 줄
   ▶ 목표: 가능한 적은 시도로 맞히세요! (현명하게 부르면 최대 7번)
테스트할 것
구분테스트 항목입력 / 조작기대 결과
(도전) 최대 N번 자동 계산기본 범위1~1007
작은 범위1~104
가장 작은 범위1~11
큰 범위1~100010
자동 반영설정값 범위를 바꾸고 안내 화면 확인문구의 숫자가 범위에 맞게 자동으로 바뀐다

최종 점검

모두 체크되면 완성입니다

  • 모든 화면의 입력 칸 모양이 같다.
  • 메뉴에서 대문자/소문자, 엉뚱한 글자, 빈 입력을 눌러도 프로그램이 꺼지지 않는다.
  • 잘못된 입력은 프로그램을 멈추지 않고, 안내 문구가 한 번만 나온다.
  • 한 판이 끝나면 Enter로 타이틀로 돌아오고, 다시 시작해도 이전 판의 내용이 남아 있지 않다.
  • 한글과 영어가 섞인 줄이 가운데 정렬로 보인다.
  • 안내 화면의 '최대 N번'이 범위를 바꿔도 맞게 나온다.
  • 정답을 맞히기 전에는 정답이 화면 어디에도 나오지 않는다.
