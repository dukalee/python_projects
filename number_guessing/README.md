# AISHIFT 숫자 맞추기 게임

터미널에서 즐기는 **숫자 맞추기(UP & DOWN) 게임**입니다.
컴퓨터가 정한 1부터 100 사이의 숫자를 UP / DOWN 힌트만 보고 **가능한 적은 시도**로 맞히세요.
파이썬 기본 문법만 사용했습니다.

## 실행 방법

- Python 3 (3.8 이상 권장), **Windows** 터미널 (화면을 지울 때 `cls` 사용)
- macOS / Linux: `main.py`의 `os.system("cls")`를 `os.system("clear")`로 바꾸세요.

```bash
python main.py
```

시작 화면에서 `S`를 입력하면 안내 후 바로 게임이 시작되고, `Q`를 입력하면 종료합니다.

## 게임 규칙

1. 컴퓨터가 `1~100` 중 숫자 하나를 정합니다.
2. 숫자를 입력하면 힌트가 나옵니다.
   - **UP ▲**: 정답이 입력한 숫자보다 큼
   - **DOWN ▼**: 정답이 입력한 숫자보다 작음
3. 정답을 맞히면 CLEAR! **목표는 가능한 적은 시도로 맞히는 것**입니다.
4. 숫자가 아니거나 범위를 벗어나면 시도를 세지 않고 다시 입력합니다.
5. 화면 위쪽에 시도 횟수가 표시됩니다.

> 매번 남은 범위의 **가운데 숫자**를 부르면 1~100 중 어떤 숫자든 최대 7번이면 맞힐 수 있습니다. (이진 탐색)

## 설정 바꾸기

`main.py` 맨 위의 값을 바꾸면 됩니다.

```python
MIN_NUM = 1       # 숫자 범위의 시작
MAX_NUM = 100     # 숫자 범위의 끝
```
