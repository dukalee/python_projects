# 숫자 맞추기 게임 — 명세

## 1. 개요

| 항목 | 내용 |
|---|---|
| 종류 | 터미널(콘솔) 1인용 숫자 맞추기(UP & DOWN) 게임 |
| 실행 | `python main.py` (Python 3.8+, Windows) |
| 목표 | `MIN_NUM`(1) ~ `MAX_NUM`(100) 중 컴퓨터가 정한 숫자를 **가능한 적은 시도**로 맞힌다 |
| 기록 | 이름 입력, 랭킹, 시간 측정, 시도 제한 없음 |

## 2. 화면 흐름

```
[타이틀] ──S──▶ [게임 안내] ──Enter──▶ [플레이: 입력 반복] ──정답──▶ [결과] ──Enter──▶ [타이틀]
    └──Q──▶ 종료
```

| 화면 | 내용 |
|---|---|
| 타이틀 | AISHIFT 로고, `S : 시작하기  Q : 종료하기` |
| 게임 안내 | 규칙 5줄, Enter로 시작 |
| 플레이 | `시도 횟수  N번` + 도전 기록 + 입력 칸 |
| 결과 | 시도 횟수 + 도전 기록 + `★ CLEAR! ★`, `N번 만에 맞혔습니다!` |

## 3. 규칙

1. 정답: `random.randint(MIN_NUM, MAX_NUM)`로 정한 정수 하나.
2. 플레이어가 숫자를 입력하면 정답과 비교해 힌트를 준다.

| 조건 | 힌트 |
|---|---|
| 입력 < 정답 | `UP   ▲  (더 큰 수)` |
| 입력 > 정답 | `DOWN ▼  (더 작은 수)` |
| 입력 = 정답 | `정답!` → CLEAR |

3. 시도 횟수에 **제한은 없다.** 맞힐 때까지 계속하며, 적을수록 좋은 결과다.
4. 시도 횟수는 올바른 입력만 센다.

## 4. 입력 처리

| 입력 | 처리 |
|---|---|
| 메인 메뉴 `s` / `q` (대소문자 무관) | 시작 / 종료. 그 밖의 입력은 무시하고 메뉴를 다시 그림 |
| 숫자가 아님 (`abc`, 빈 입력, 음수 부호, 소수점 포함) | `숫자만 입력해 주세요.` — **시도를 세지 않음** |
| 범위 밖 (`0`, `101`) | `1부터 100 사이의 숫자를 입력해 주세요.` — **시도를 세지 않음** |
| 올바른 입력 | 힌트 계산, 기록에 추가, 시도 +1 |

오류 안내(`※ …`)는 다음 화면 입력 칸 위에 한 번만 나온다.

## 5. 화면 요소

- **시도 표시줄**: `시도 횟수  3번`
- **도전 기록**: `1회    50   →   DOWN ▼  (더 작은 수)` 형태로 순서대로 쌓인다. 기록이 없으면 `아직 도전 기록이 없습니다.`
- **안내 화면의 효율 문구**: `best_tries()`가 범위 크기에서 계산한 값. 1~100이면 7 — 범위를 절반씩 줄이면 최대 7번이면 반드시 맞힐 수 있다는 뜻 (이진 탐색).

## 6. 설정값 (`main.py` 맨 위)

| 이름 | 기본값 | 뜻 |
|---|---|---|
| `MIN_NUM` | 1 | 숫자 범위의 시작 |
| `MAX_NUM` | 100 | 숫자 범위의 끝 |
| `WIDTH` | 62 | 가운데 정렬 기준 폭 |

범위를 바꾸면 안내 문구와 효율 문구가 함께 바뀐다.

## 7. 주요 함수

| 함수 | 역할 |
|---|---|
| `clear`, `ask`, `width`, `pad_left`, `margin`, `center`, `center_block`, `show_title` | 화면 출력과 정렬 |
| `check_guess(text)` | 올바르면 `""`, 아니면 오류 문구 반환 |
| `hint(guess, answer)` | UP / DOWN / 정답 글자 반환 |
| `best_tries()` | 이진 탐색으로 필요한 최대 횟수 계산 |
| `show_status(used)`, `show_history(history)` | 시도 표시줄, 도전 기록 |
| `intro()`, `play()` | 안내 화면, 한 판 진행과 결과 |

## 9. 제약과 알려진 사항

- Windows 전용: 화면 지우기에 `cls`를 쓴다.
- 기록 저장 기능이 없다. 한 판이 끝나면 내용은 사라진다.
- 포기하는 방법이 없다. (Ctrl+C로 강제 종료)
- 입력 종료(EOF)는 별도로 처리하지 않는다.
