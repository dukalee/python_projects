# 카드 뒤집기 게임 — 명세

## 1. 개요

| 항목 | 내용 |
|---|---|
| 종류 | 터미널(콘솔) 1인용 카드 짝 맞추기 게임 |
| 실행 | `python main.py` (Python 3.8+, Windows) |
| 목표 | 뒤집힌 카드 16장에서 같은 문양 8쌍을 **가능한 적은 시도**로 모두 찾는다 |
| 기록 | 이름 입력, 랭킹, 시간 측정, 시도 제한 없음 |

## 2. 화면 흐름

```
[타이틀] ──S──▶ [게임 안내] ──Enter──▶ ┌▶ [첫 번째 카드 선택]
    └──Q──▶ 종료                       │        ▼
                                       │  [두 번째 카드 선택]
                                       │        ▼
                                       │  [두 장 공개 + 결과] ──Enter──┐
                                       └──────── 짝이 남음 ◀──────────┘
                                                모두 맞힘 ──▶ [결과] ──Enter──▶ [타이틀]
```

| 화면 | 내용 |
|---|---|
| 타이틀 | AISHIFT 로고, `S : 시작하기  Q : 종료하기` |
| 게임 안내 | 규칙 5줄, Enter로 시작 |
| 카드 선택 | `시도 횟수  N번`, `맞춘 짝  x / 8`, 카드 판, 입력 칸 |
| 두 장 공개 | 선택한 두 카드가 열린 판. 짝이 맞으면 `짝이 맞았습니다!  (♠)`, 틀리면 문구 없이 `Enter를 누르면 계속합니다.` |
| 결과 | 점수판 + 카드 판 + `★ CLEAR! ★`, `N번 만에 모든 짝을 맞혔습니다!` |

## 3. 카드 판

- 문양: `SYMBOLS` = `♠ ♥ ♦ ♣ ★ ● ▲ ♪` (8종), 문양마다 2장 → 총 16장
- 배치: `random.shuffle`로 섞어 `COLS`(4)장씩 4줄. 카드 번호는 왼쪽 위부터 1~16
- 카드 한 장은 5칸 `[ x ]` 모양이다.

| 상태 | 표시 | 예 |
|---|---|---|
| 뒤집혀 있음 | 가운데에 번호 | `[ 3 ]`, `[ 10]` |
| 열려 있음 (선택한 카드 / 이미 맞춘 카드) | 가운데에 문양 | `[ ♠ ]` |

## 4. 규칙

1. 첫 번째 카드, 두 번째 카드 번호를 차례로 입력해 두 장을 뒤집는다. 두 장을 뒤집는 것이 **1번 시도**다.
2. 두 장의 문양이 같으면 **짝 성공**: 그 두 장은 계속 열려 있고 맞춘 짝이 1 늘어난다.
3. 문양이 다르면 두 장은 다시 뒤집힌다. (시도 횟수는 그대로 1 늘어난다)
4. 8쌍을 모두 맞히면 CLEAR. 이론상 최소 시도는 8번이다.
5. 시도 횟수 제한과 GAME OVER는 없다.

## 5. 입력 처리

| 입력 | 처리 |
|---|---|
| 메인 메뉴 `s` / `q` (대소문자 무관) | 시작 / 종료. 그 밖의 입력은 무시하고 메뉴를 다시 그림 |
| 숫자가 아니거나 1~16 밖 | `1부터 16 사이의 카드 번호를 입력해 주세요.` — **시도를 세지 않음** |
| 이미 짝을 맞춘 카드 | `이미 짝을 맞춘 카드입니다.` — 시도를 세지 않음 |
| 두 번째에 같은 카드를 다시 선택 | `방금 뒤집은 카드입니다. 다른 카드를 골라 주세요.` — 시도를 세지 않음 |

잘못 입력하면 안내 문구와 함께 **같은 선택 화면을 다시** 보여 준다.

## 6. 상태

| 변수 | 형태 | 뜻 |
|---|---|---|
| `cards` | 길이 16 리스트 | 위치별 문양 |
| `matched` | 길이 16 리스트(True/False) | 위치별 짝 성공 여부 |
| `pairs` | 정수 | 맞춘 짝 수 (0~8) |
| `turns` | 정수 | 시도 횟수 |
| `first`, `second` | 정수 | 한 턴에 선택한 카드의 위치(0부터) |

종료 조건: `pairs == len(SYMBOLS)`

## 7. 설정값 (`main.py` 맨 위)

| 이름 | 기본값 | 뜻 |
|---|---|---|
| `SYMBOLS` | `"♠♥♦♣★●▲♪"` | 카드 문양. 글자 하나가 한 쌍 (늘리면 카드도 늘어남) |
| `COLS` | 4 | 한 줄에 놓는 카드 수 |
| `WIDTH` | 62 | 가운데 정렬 기준 폭 |

## 8. 주요 함수

| 함수 | 역할 |
|---|---|
| `clear`, `ask`, `width`, `margin`, `center`, `center_block`, `show_title` | 화면 출력과 정렬 |
| `make_cards()` | 문양 2장씩 만들어 섞은 리스트 반환 |
| `card_text(i, cards, matched, flipped, reveal)` | 카드 한 장의 표시 글자 |
| `show_board(cards, matched, flipped, reveal)` | 카드 판 출력 |
| `show_status(turns, pairs)` | 시도 횟수와 맞춘 짝 표시줄 |
| `check_pick(text, cards, matched, flipped)` | 올바르면 `""`, 아니면 오류 문구 |
| `pick_card(...)` | 올바른 카드 번호를 받을 때까지 묻고 위치(0부터)를 반환 |
| `intro()`, `play()` | 안내 화면, 한 판 진행과 결과 |

## 10. 제약과 알려진 사항

- Windows 전용: 화면 지우기에 `cls`를 쓴다.
- 일부 콘솔에서는 `♠ ★ ●` 같은 기호가 두 칸 너비로 그려져 카드 줄이 어긋날 수 있다. 그럴 때는 `SYMBOLS`를 `"ABCDEFGH"`처럼 바꾼다. (카드 줄맞춤은 한글 외 글자를 1칸으로 계산한다)
- 짝을 맞추지 못해도 기회가 줄지 않으므로 결과가 시도 횟수로만 비교된다. 기록 저장은 없다.
- 입력 종료(EOF)나 Ctrl+C는 별도로 처리하지 않는다.
