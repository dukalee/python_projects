타이틀 화면 만들기

필요한 기능
화면 지우기와 입력 칸
  • 화면을 지우는 기능
  • 항상 같은 모양( > )의 입력 칸. 입력한 글자의 앞뒤 공백은 없앤다.
  • 맨 위 설정값: 화면 폭(62), 가로줄, 입력 칸 모양
글자 폭 계산
  • 글자가 화면에서 차지하는 칸 수 계산: 한글 2칸, 영어·숫자·기호 1칸
가운데 정렬 출력
  • 한 줄 가운데 정렬 출력, 여러 줄을 '가장 긴 줄' 기준으로 한꺼번에 가운데 정렬 출력
타이틀 화면 그리기
  • 가로줄, AISHIFT 문자 그림(로고), 부제 카드 뒤집기, 메뉴 안내가 있는 타이틀 화면
메인 메뉴 반복
  • 메뉴 입력(대문자·소문자 모두 인식): S 시작하기, Q 종료하기
  • 프로그램이 계속 반복되며 타이틀로 돌아오고, Q를 눌러야만 끝난다
  • 아직 게임이 없으므로 S는 '준비 중' 문구를 보여 주고 Enter 후 타이틀로 돌아온다

게임 로직 1 — 카드 만들기와 카드 판

필요한 기능
카드 만들기
  • 문양 8종(♠ ♥ ♦ ♣ ★ ● ▲ ♪)을 2장씩 모아 카드 16장을 만들고 무작위로 섞는다
  • 문양 목록은 설정값. 문양을 늘리거나 줄이면 카드 수도 따라 바뀐다
  • 카드 위치는 화면에서 1번부터 센다
카드 한 장의 모양
  • 카드 한 장은 5칸짜리 [ x ] 모양. 뒤집힌 카드는 가운데에 번호, 열려 있는 카드는 가운데에 문양
  • 카드마다 '이미 짝을 맞췄는지'와 '지금 뒤집은 카드인지'를 기억해 모양에 반영한다
  • 두 자리 번호도 한 자리와 폭이 같다 ([ 10])
카드 판 출력
  • 4장씩 한 줄로 묶고, 줄 사이에 빈 줄을 넣어 가운데 정렬로 보여 준다
결과물 예시 화면

테스트할 것
구분테스트 항목입력 / 조작기대 결과
카드 만들기카드 수카드를 만들어 출력16장
문양별 장수각 문양 개수 확인8종류가 정확히 2장씩
섞임여러 번 만들어 비교실행할 때마다 배치가 다르다
문양 줄이기문양 목록에서 하나 삭제14장이 된다
문양 늘리기문양 목록에 하나 추가18장이 된다
카드 한 장의 모양번호 폭한 자리와 두 자리 번호[ 9 ] 와 [ 10] 의 폭이 같아 줄이 맞는다
카드 열기1번을 열린 상태로[ ♠ ] 처럼 가운데에 문양이 보인다
끝 번호 열기16번을 열린 상태로맨 끝 카드가 올바르게 열린다 (번호가 한 칸 어긋나지 않는다)
짝 맞춘 카드짝을 맞춘 상태로 표시계속 열려 있다
카드 판 출력초기 화면모든 카드 뒤집힘[ 1 ] ~ [ 16 ] 이 4개씩 4줄로 순서대로 보인다
줄 구성판 전체줄 사이에 빈 줄이 있고, 맨 아래에는 빈 줄이 없다
가운데 정렬판 전체화면 가운데에 놓인다
열 수 설정한 줄 카드 수를 2로 변경2장씩 8줄로 나온다

게임 로직 2 — 카드 고르기

필요한 기능
카드 번호 입력 확인
  • 범위 밖/숫자 아님, 이미 짝을 맞춘 카드, 방금 뒤집은 카드(두 번째 선택에서)는 각각 다른 안내 문구
카드 상태 확인
  • 범위 밖/숫자 아님, 이미 짝을 맞춘 카드, 방금 뒤집은 카드(두 번째 선택에서)는 각각 다른 안내 문구
올바를 때까지 다시 묻기
  • 카드 번호를 입력받는다. 올바른 번호가 들어올 때까지 같은 화면에서 다시 묻는다
  • 잘못된 입력은 시도로 세지 않는다

게임 로직 3 — 한 번의 시도 (두 장 뒤집기)

필요한 기능
첫 번째 · 두 번째 카드 선택
  • 첫 번째 카드를 고른다 → 두 번째 선택 화면에는 첫 번째 카드가 열려 있다
두 장 공개 화면
  • 두 카드를 모두 연 화면을 보여 준다
  • 두 경우 모두 Enter를 누르면 계속되고, 시도 횟수가 1 늘어난다
짝 판정과 반영
  • 문양이 같으면 짝 성공: 두 카드는 계속 열려 있고 맞춘 짝 수가 늘며 짝이 맞았습니다! 문구
  • 문양이 다르면 문구 없이 다음 화면에서 다시 뒤집힌다
결과물 예시 화면
첫 번째 · 두 번째 카드 선택
선택 흐름
  [ 1 ]  [ 2 ]  [ 3 ] ...   첫 번째 카드 번호: 1
  [ ♠ ]  [ 2 ]  [ 3 ] ...   두 번째 카드 번호: 3   (첫 카드가 열려 있음)
두 장 공개 화면
짝이 맞았을 때
                 [ ♠ ]   [ 2 ]   [ ♠ ]   [ 4 ]
                 ...

                  짝이 맞았습니다!  (♠)

               Enter를 누르면 계속합니다.
짝이 틀렸을 때 (문구 없음)
                 [ ♠ ]   [ 2 ]   [ ♥ ]   [ 4 ]
                 ...

               Enter를 누르면 계속합니다.
짝 판정과 반영
판정 결과
  ♠ = ♠ → 짝 성공: 두 카드 계속 열림, 맞춘 짝 + 1
  ♠ ≠ ♥ → 실패: 두 카드 다시 뒤집힘, 맞춘 짝 그대로
  (둘 다 시도 횟수 + 1)
테스트할 것
구분테스트 항목입력 / 조작기대 결과
첫 번째 · 두 번째 카드 선택첫 카드 선택1번 선택두 번째 선택 화면에서 1번 카드가 열려 있다
두 장 공개 화면두 장 공개두 번째 카드까지 선택두 카드가 모두 열린 판이 보인다
Enter 대기결과 화면에서 입력 없이Enter를 누를 때까지 다음 화면으로 안 넘어간다
짝 판정과 반영맞는 쌍같은 문양 두 장'짝이 맞았습니다! (문양)' 문구, Enter 후에도 열려 있다
틀린 쌍다른 문양 두 장문구 없음, Enter 후 두 카드가 다시 번호로 돌아간다
시도 횟수맞는 쌍과 틀린 쌍 각각둘 다 시도 횟수가 1 늘어난다
맞춘 짝 수맞는 쌍과 틀린 쌍 각각맞는 쌍일 때만 1 늘어난다

게임 로직 4 — 한 판 완성

필요한 기능
점수판 (시도 횟수 · 맞춘 짝)
  • 화면 위쪽 표시줄: 시도 횟수와 맞춘 짝 x / 8
한 판 반복과 초기화
  • 8쌍을 모두 찾을 때까지 '한 번의 시도'를 반복한다 (실패 없음)
  • 판이 시작될 때마다 카드를 새로 섞고, 상태(맞춘 짝, 시도 횟수)를 처음으로 되돌린다

한 판 반복과 초기화
한 판의 시작과 끝
  시작: 새 배치, 시도 0, 맞춘 짝 0, 모두 뒤집힘
  반복: 한 번의 시도 × N번

최종 점검

모두 체크되면 완성입니다

  • 모든 화면의 입력 칸 모양이 같다.
  • 메뉴에서 대문자/소문자, 엉뚱한 글자, 빈 입력을 눌러도 프로그램이 꺼지지 않는다.
  • 잘못된 입력은 프로그램을 멈추지 않고, 안내 문구가 한 번만 나온다.
  • 한 판이 끝나면 Enter로 타이틀로 돌아오고, 다시 시작해도 이전 판의 내용이 남아 있지 않다.
  • 한글과 영어가 섞인 줄이 가운데 정렬로 보인다.
  • 이미 맞춘 카드 / 방금 뒤집은 카드 / 범위 밖 번호를 고를 수 없다.
  • 틀린 쌍은 문구 없이 다시 뒤집힌다.
  • 목숨이나 GAME OVER 없이 시도 횟수만 센다.
