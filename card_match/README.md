# AISHIFT 카드 뒤집기 게임

터미널에서 즐기는 **카드 뒤집기(짝 맞추기) 게임**입니다.
뒤집혀 있는 카드 16장 중에서 같은 문양 두 장을 찾아 8쌍을 모두 맞히세요.
파이썬 기본 문법만 사용했습니다.

## 실행 방법

- Python 3 (3.8 이상 권장), **Windows** 터미널 (화면을 지울 때 `cls` 사용)
- macOS / Linux: `main.py`의 `os.system("cls")`를 `os.system("clear")`로 바꾸세요.

```bash
python main.py
```

시작 화면에서 `S`를 입력하면 안내 후 바로 게임이 시작되고, `Q`를 입력하면 종료합니다.

## 게임 규칙

1. 4 x 4 판에 카드 16장(♠ ♥ ♦ ♣ ★ ● ▲ ♪ 8쌍)이 놓여 있고, 카드 뒷면에는 번호(1~16)만 보입니다.
2. 카드 번호를 두 번 입력해서 카드 두 장을 뒤집습니다. (이것이 **1번 시도**)
3. 문양이 같으면 **짝 성공**, 그 카드는 계속 열려 있습니다.
4. 문양이 다르면 카드가 다시 뒤집힙니다.
5. 8쌍을 모두 맞히면 CLEAR! **목표는 가능한 적은 시도로 맞히는 것**입니다.
6. 없는 번호이거나 이미 맞춘 카드를 고르면 시도를 세지 않고 다시 입력합니다.

카드 모양

| 모양 | 뜻 |
|:---:|---|
| `[ 3 ]` | 뒤집혀 있는 카드 (번호만 보임) |
| `[ ♠ ]` | 열려 있는 카드 (지금 뒤집은 카드, 이미 짝을 맞춘 카드) |

## 설정 바꾸기

`main.py` 맨 위의 값을 바꾸면 됩니다.

```python
SYMBOLS = "♠♥♦♣★●▲♪"   # 카드 문양 (글자 하나가 한 쌍, 늘리면 카드도 늘어남)
COLS = 4               # 한 줄에 놓는 카드 수
```

> 일부 콘솔에서는 `♠ ★ ●` 같은 기호가 두 칸 너비로 그려져 카드 줄이 어긋날 수 있습니다. 그럴 때는 `SYMBOLS`를 `"ABCDEFGH"`처럼 바꾸세요.
