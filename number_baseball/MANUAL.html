타이틀 화면 만들기

필요한 기능
화면 지우기와 입력 칸
  • 화면을 지우는 기능
  • 항상 같은 모양( > )의 입력 칸. 입력한 글자의 앞뒤 공백은 없앤다.
  • 맨 위 설정값: 화면 폭(62), 가로줄, 입력 칸 모양
글자 폭 계산
  • 글자가 화면에서 차지하는 칸 수 계산: 한글 2칸, 영어·숫자·기호 1칸
가운데 정렬 출력
  • 한 줄 가운데 정렬 출력, 여러 줄을 '가장 긴 줄' 기준으로 한꺼번에 가운데 정렬 출력
타이틀 화면 그리기
  • 가로줄, AISHIFT 문자 그림(로고), 부제 숫자 야구, 메뉴 안내가 있는 타이틀 화면
메인 메뉴 반복
  • 메뉴 입력(대문자·소문자 모두 인식): S 시작하기, Q 종료하기
  • 프로그램이 계속 반복되며 타이틀로 돌아오고, Q를 눌러야만 끝난다
  • 아직 게임이 없으므로 S는 '준비 중' 문구를 보여 주고 Enter 후 타이틀로 돌아온다

게임 로직 1 — 정답 만들기와 입력 확인

필요한 기능
정답 만들기
  • 서로 다른 숫자 3개를 무작위로 정한다. (자릿수는 설정값)
  • 0으로 시작할 수 있다. 앞의 0이 사라지면 안 된다.
입력 확인 (자릿수·숫자)
  • 입력이 올바른 추측인지 확인하고, 틀렸다면 이유를 알려 준다
  • 자릿수가 다르거나 숫자가 아님 / 같은 숫자가 겹침 → 각각 다른 안내 문구
입력 확인 (중복)
  • 자릿수가 다르거나 숫자가 아님 / 같은 숫자가 겹침 → 각각 다른 안내 문구
  • 두 경우 모두 기회를 쓰지 않는 입력이다
결과물 예시 화면

게임 로직 2 — 스트라이크·볼 판정

필요한 기능
스트라이크·볼 세기
  • 추측과 정답을 비교해 스트라이크(숫자와 자리 모두 같음)와 볼(숫자는 있지만 자리가 다름)의 개수를 센다
  • 한 자리는 스트라이크, 볼, 해당 없음 중 하나로만 센다
결과 글자 만들기
  • 결과를 1S 2B 형식으로 보여 주고, 둘 다 0이면 OUT
결과물 예시 화면
스트라이크·볼 세기
판정 예시
   (정답이 407일 때)
   407   →   3S 0B
   470   →   1S 2B
   123   →   OUT
   740   →   0S 3B
   174   →   0S 2B
   412   →   1S 0B
결과 글자 만들기
결과 글자 예
   (S=1, B=2) → 1S 2B
   (S=3, B=0) → 3S 0B
   (S=0, B=0) → OUT
테스트할 것
구분테스트 항목입력 / 조작기대 결과
스트라이크·볼 세기모두 일치입력 4073S 0B
자리만 다름4701S 2B
0이 앞0471S 2B
전부 볼7400S 3B
일부 볼1740S 2B (1은 정답에 없음)
일부 스트라이크4121S 0B
합 검증위 입력 전부스트라이크 + 볼이 3을 넘는 경우가 없다
결과 글자 만들기하나도 없음123OUT

게임 로직 3 — 기회와 한 판 진행

필요한 기능
남은 기회 표시 (하트)
  • 쓴 횟수에 맞춰 남은 기회를 ♥, 쓴 기회를 ♡로 보여 주는 표시줄
  • 전체 하트 수 = 허용 시도 횟수(설정값, 10)
도전 기록 화면
  • 매번 화면을 새로 그린다: 하트 표시줄 → 도전 기록 → 입력 안내 → 입력 칸
  • 도전 기록: 입력한 숫자와 결과(1S 2B / OUT)가 순서대로 쌓인다
반복 조건 (기회·맞힘)
  • 기회가 남아 있고 아직 못 맞힌 동안 계속 입력받는다
  • 스트라이크가 3개면 맞힌 것으로 끝난다
잘못된 입력 처리
  • 잘못된 입력은 기회를 쓰지 않고, 안내 문구를 다음 화면에 한 번만 보여 준다

마무리 — 안내·결과 화면과 메뉴 연결

필요한 기능
게임 안내 화면
  • 게임 안내 화면: 규칙을 보여 주고 Enter로 시작
결과 화면 (CLEAR / GAME OVER)
  • 결과 화면: 하트 표시줄 + 전체 도전 기록 + 결과 문구
  • 맞힘 → CLEAR와 맞힌 횟수 / 못 맞힘 → GAME OVER와 정답 공개
메뉴와 연결
  • 메인 메뉴 S에 연결: 안내 → 한 판 → 결과 → 타이틀
결과물 예시 화면
게임 안내 화면

  ▶ 컴퓨터가 서로 다른 숫자 3개를 정했습니다. 맞혀 보세요!
  ▶ 숫자 3개를 입력하고 Enter를 누르면 힌트가 나옵니다.
  ▶ 스트라이크(S): 숫자도 맞고 자리도 맞음
  ▶ 볼(B): 숫자는 있지만 자리가 다름
  ▶ 아웃(OUT): 하나도 맞지 않음
  ▶ 10번 안에 맞히면 승리!

최종 점검

모두 체크되면 완성입니다

  • 모든 화면의 입력 칸 모양이 같다.
  • 메뉴에서 대문자/소문자, 엉뚱한 글자, 빈 입력을 눌러도 프로그램이 꺼지지 않는다.
  • 잘못된 입력은 프로그램을 멈추지 않고, 안내 문구가 한 번만 나온다.
  • 한 판이 끝나면 Enter로 타이틀로 돌아오고, 다시 시작해도 이전 판의 내용이 남아 있지 않다.
  • 한글과 영어가 섞인 줄이 가운데 정렬로 보인다.
