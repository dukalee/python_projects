# 숫자 야구 게임 — 명세

## 1. 개요

| 항목 | 내용 |
|---|---|
| 종류 | 터미널(콘솔) 1인용 숫자 야구 게임 |
| 실행 | `python main.py` (Python 3.8+, Windows) |
| 목표 | 컴퓨터가 정한 서로 다른 3자리 숫자를 스트라이크/볼 힌트로 `MAX_TRIES`(10)번 안에 맞힌다 |
| 기록 | 이름 입력, 랭킹, 시간 측정 없음 |

## 2. 화면 흐름

```
[타이틀] ──S──▶ [게임 안내] ──Enter──▶ [플레이: 입력 반복] ──▶ [결과] ──Enter──▶ [타이틀]
    └──Q──▶ 종료
```

| 화면 | 내용 |
|---|---|
| 타이틀 | AISHIFT 로고, `S : 시작하기  Q : 종료하기` |
| 게임 안내 | 규칙 6줄, Enter로 시작 |
| 플레이 | 기회 표시줄(하트) + 지금까지의 도전 기록 + 입력 칸 |
| 결과 | 기회 표시줄 + 도전 기록 + `★ CLEAR! ★` 또는 `GAME OVER`(정답 공개) |

## 3. 규칙

1. 정답: `0~9` 중 **서로 다른 숫자 `DIGITS`(3)개**를 무작위로 뽑는다. `0`으로 시작할 수 있다. (예: `012`)
2. 플레이어는 같은 자릿수의 숫자를 입력한다.
3. 판정은 자리별로 한다.

| 결과 | 조건 |
|---|---|
| 스트라이크(S) | 숫자와 자리가 모두 같음 |
| 볼(B) | 정답에 있는 숫자지만 자리가 다름 |
| 아웃(OUT) | 스트라이크도 볼도 없음 |

   - 표시: `1S 2B`, `0S 1B`, `OUT`
4. `3S`면 CLEAR, 시도 `MAX_TRIES`(10)번을 모두 쓰고도 못 맞히면 GAME OVER.
5. 예) 정답 `407`: 입력 `470` → `1S 2B`, 입력 `123` → `OUT`, 입력 `407` → `3S 0B`(CLEAR)

## 4. 입력 처리

| 입력 | 처리 |
|---|---|
| 메인 메뉴 `s` / `q` (대소문자 무관) | 시작 / 종료. 그 밖의 입력은 무시하고 메뉴를 다시 그림 |
| 자릿수가 다르거나 숫자가 아님 | `3자리 숫자를 입력해 주세요.` — **기회를 쓰지 않음** |
| 같은 숫자가 겹침 (`112`) | `서로 다른 숫자를 입력해 주세요.` — **기회를 쓰지 않음** |
| 올바른 입력 | 판정 후 기록에 추가, 기회 1 감소 |

오류 안내(`※ …`)는 다음 화면 입력 칸 위에 한 번만 나온다.

## 5. 화면 요소

- **기회 표시줄**: `기회   ♥♥♥♥♥♥♥♡♡♡   (7번 남음)` — 남은 기회 `♥`, 쓴 기회 `♡`
- **도전 기록**: `1회   345   →   OUT` 형태로 입력 순서대로 쌓인다. 기록이 없으면 `아직 도전 기록이 없습니다.`
- 입력 칸: `  > `

## 6. 설정값 (`main.py` 맨 위)

| 이름 | 기본값 | 뜻 |
|---|---|---|
| `DIGITS` | 3 | 맞혀야 하는 자릿수 (최대 10, 서로 다른 숫자이므로) |
| `MAX_TRIES` | 10 | 허용 시도 횟수 |
| `WIDTH` | 62 | 가운데 정렬 기준 폭 |

## 7. 주요 함수

| 함수 | 역할 |
|---|---|
| `clear`, `ask`, `width`, `pad_left`, `margin`, `center`, `center_block`, `show_title` | 화면 출력과 정렬 |
| `make_answer()` | 서로 다른 숫자 `DIGITS`개를 뽑아 글자로 반환 |
| `check_guess(guess)` | 올바르면 `""`, 아니면 오류 문구 반환 |
| `judge(answer, guess)` | `(스트라이크, 볼)` 반환 |
| `result_text(strike, ball)` | `1S 2B` / `OUT` 글자 만들기 |
| `show_status(used)` | 기회 표시줄 |
| `intro()`, `play()` | 안내 화면, 한 판 진행과 결과 |

## 9. 제약과 알려진 사항

- Windows 전용: 화면 지우기에 `cls`를 쓴다.
- 기록 저장 기능이 없다. 한 판이 끝나면 내용은 사라진다.
- 입력 종료(EOF)나 Ctrl+C는 별도로 처리하지 않는다.
