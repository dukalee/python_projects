타이틀 화면 만들기

필요한 기능
화면 지우기와 입력 칸
  • 화면을 지우는 기능
  • 항상 같은 모양( > )의 입력 칸. 입력한 글자의 앞뒤 공백은 없앤다.
  • 맨 위 설정값: 화면 폭(62), 가로줄, 입력 칸 모양
글자 폭 계산
  • 글자가 화면에서 차지하는 칸 수 계산: 한글 2칸, 영어·숫자·기호 1칸
가운데 정렬 출력
  • 한 줄 가운데 정렬 출력, 여러 줄을 '가장 긴 줄' 기준으로 한꺼번에 가운데 정렬 출력
타이틀 화면 그리기
  • 가로줄, AISHIFT 문자 그림(로고), 부제 영문 타자연습, 메뉴 안내가 있는 타이틀 화면
메인 메뉴 반복
  • 메뉴 입력(대문자·소문자 모두 인식): S 시작하기, R 랭킹 보기, Q 종료하기
  • 프로그램이 계속 반복되며 타이틀로 돌아오고, Q를 눌러야만 끝난다
  • 아직 게임이 없으므로 S는 '준비 중' 문구를 보여 주고 Enter 후 타이틀로 돌아온다

게임 로직 1 — 문장 준비와 입력·시간 측정

필요한 기능
문장 파일 읽기
  • 연습 문장 파일: 한 줄에 한 문장, 20개 이상 (UTF-8)
섞어서 10개 고르기
  • 파일을 읽어 빈 줄과 앞뒤 공백은 빼고, 무작위로 섞어 10개를 고른다 (한 번에 풀 문장 수는 설정값)
  • 문장이 10개보다 적으면 있는 만큼만 쓴다
문장 보여 주고 입력받기
  • 문장을 보여 주고 입력을 받는다
  • 입력한 글자는 공백까지 그대로 보관한다
걸린 시간 재기
  • 문장이 나온 순간부터 Enter를 누를 때까지 걸린 시간을 초 단위로 잰다. 0에 가까운 값은 0.001초로 보정한다

게임 로직 2 — 정확도·WPM 계산

필요한 기능
맞은 글자 수와 정확도
  • 맞게 친 글자: 정답과 입력의 같은 위치 글자가 같은 것 (둘 중 짧은 쪽 길이까지만 비교)
  • 정확도(%) = 맞게 친 글자 수 ÷ 정답 문장의 전체 글자 수 × 100
WPM 계산
  • 문장 하나의 WPM = (입력한 글자 수 ÷ 5) ÷ 걸린 시간(분)
평균 계산
  • 여러 값의 평균. 값이 하나도 없으면 평균 0, 정확도 100
결과물 예시 화면
맞은 글자 수와 정확도
계산 예시
   정답 abc def / 입력 abc deg → 맞은 글자 6 / 전체 7
   정답 abc     / 입력 ab      → 2 / 3
   정답 abc     / 입력 abcd    → 3 / 3 (넘친 글자는 세지 않음)
WPM 계산
WPM 예시
   25글자를 5초에 입력
   (25 ÷ 5) ÷ (5 ÷ 60) = 60 WPM
평균 계산
평균 예
   [76.0, 55.0, 60.0] → 63.7
   [ ] (값 없음)         → 0
테스트할 것
구분테스트 항목입력 / 조작기대 결과
맞은 글자 수와 정확도맞은 글자(오타 1개)정답 abc def, 입력 abc deg맞은 글자 6 / 전체 7
입력이 모자람정답 abc, 입력 ab맞은 글자 2 / 전체 3
입력이 넘침정답 abc, 입력 abcd맞은 글자 3 / 전체 3 (넘친 글자는 세지 않음)
정확도 계산정답 전체 100글자 중 95글자 일치95.0%
글자 수 0전체 글자 0일 때 정확도100 (오류 없음)
WPM 계산WPM25글자를 5초에60
단위 변환초 대신 분으로 계산했는지5초면 약 0.083분으로 계산되어 위 WPM이 60이 된다
평균 계산빈 목록 평균값이 없는 목록의 평균0 (오류 없음)

게임 로직 3 — 점수판과 한 판 진행

필요한 기능
진행 막대
  • 화면 맨 위에 항상 보이는 점수판: 이름, 진행 막대(■ 끝낸 칸 / □ 남은 칸), 현재·최고·평균 WPM, 정확도
수치 표시 (WPM·정확도)
  • 값은 소수 첫째 자리까지 반올림. 기록이 없을 때도 오류 없이 0으로 보인다
10문장 반복 진행
  • 문장 10개를 차례로 진행한다: 화면 지우기 → 점수판 → 문장 → 입력·시간 → 기록 갱신
결과 판정 (CLEAR / GAME OVER)
  • 끝나면 결과 화면: 점수판(10/10)과 결과 문구
  • 정확도 95% 이상 → CLEAR와 '랭킹에 기록되었습니다!' / 미만 → GAME OVER와 '기록되지 않았습니다.'

게임 로직 4 — 랭킹 저장과 읽기

필요한 기능
랭킹 저장
  • CLEAR일 때 기록(이름, 정확도, 평균 WPM, 최고 WPM)을 랭킹 파일 맨 뒤에 한 줄 덧붙여 저장한다 (소수 둘째 자리)
  • 이름 안의 쉼표는 공백으로 바꿔 저장한다
랭킹 읽기
  • 파일을 읽어 기록 목록으로 만든다. 파일이 없으면 빈 목록, 형식이 이상한 줄은 무시한다
결과물 예시 화면
랭킹 저장
한 줄에 한 명
   (랭킹 파일 내용)
   Tom,99.37,96.36,108.04
   Amy,100.0,88.5,101.2
랭킹 읽기
읽은 결과 (목록)
  [이름, 정확도, 평균, 최고]
  ['Tom', 99.37, 96.36, 108.04]
  ['Amy', 100.0, 88.5, 101.2]
테스트할 것
구분테스트 항목입력 / 조작기대 결과

필요한 기능
순위 비교
  • 두 기록 중 어느 쪽이 더 높은 순위인지 알려 주는 기능
  • 비교 순서: 정확도 ↓ → 평균 WPM ↓ → 최고 WPM ↓ (앞 항목이 같을 때만 다음 항목 비교)
버블 정렬
  • 기록 목록을 순위가 높은 순서로 정렬 (내장 정렬 대신 버블 정렬을 직접 구현)
  • 이웃한 두 기록을 비교해, 순위가 낮은 쪽이 뒤로 가도록 자리를 바꾸는 것을 반복한다
  • 바퀴를 돌 때마다 맨 뒤 하나는 자리가 확정되므로 비교 범위가 줄어든다

  • 열이 맞도록 폭을 계산해 정렬한다 (한글 이름 포함)
  • 기록이 없으면 안내 문구. Enter를 누르면 메인으로

최종 점검

모두 체크되면 완성입니다

  • 모든 화면의 입력 칸 모양이 같다.
  • 메뉴에서 대문자/소문자, 엉뚱한 글자, 빈 입력을 눌러도 프로그램이 꺼지지 않는다.
