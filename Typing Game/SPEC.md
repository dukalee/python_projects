# 영문 타자연습 게임 — 명세

## 1. 개요

| 항목 | 내용 |
|---|---|
| 종류 | 터미널(콘솔) 1인용 타자연습 게임 |
| 실행 | `python main.py` (Python 3.8+, Windows) |
| 목표 | 영어 문장 10개를 정확하고 빠르게 입력해 타수(WPM)와 정확도를 높인다 |
| 기록 | 정확도 95% 이상이면 랭킹(`ranking.txt`)에 기록, 상위 5명 표시 |

## 2. 화면 흐름

```
[타이틀] ──S──▶ [게임 안내 + 이름 입력] ──▶ [문장 1..10 반복] ──▶ [결과] ──Enter──▶ [타이틀]
    ├──R──▶ [랭킹 TOP 5] ──Enter──▶ [타이틀]
    └──Q──▶ 종료
```

| 화면 | 내용 |
|---|---|
| 타이틀 | AISHIFT 로고, `S : 시작하기  R : 랭킹 보기  Q : 종료하기` |
| 게임 안내 | 규칙 5줄, 이름 입력 (빈 이름이면 다시 입력) |
| 플레이 | 점수판(이름, 진행 막대 `■□`, 현재/최고/평균 WPM, 정확도) + 문장 + 입력 칸 |
| 결과 | 점수판 + `★ CLEAR! ★`(기록됨) 또는 `GAME OVER`(기록 안 됨) |
| 랭킹 | 순위, 이름, 정확도, 평균 WPM, 최고 WPM 표 |

## 3. 규칙

1. `text.txt`에서 빈 줄을 뺀 문장을 읽어 무작위로 섞고 앞에서 `COUNT`(10)개를 뽑는다. 문장이 10개보다 적으면 있는 만큼만 진행한다.
2. 문장이 화면에 나온 순간부터 Enter를 누를 때까지 걸린 시간을 잰다. (0.001초 미만은 0.001초로 보정)
3. 문장 입력이 끝날 때마다 점수판이 갱신된다.

### 점수 계산

| 값 | 식 |
|---|---|
| 문장별 WPM | `(입력한 글자 수 ÷ 5) ÷ 걸린 시간(분)` — 5글자를 1단어로 본다 |
| 평균 WPM | 문장별 WPM의 평균 |
| 최고 WPM | 문장별 WPM의 최댓값 |
| 정확도(%) | `맞게 친 글자 수 ÷ 전체 글자 수 × 100` |

- 맞게 친 글자: 정답과 입력의 **같은 위치** 글자가 같은 경우. 입력이 모자라거나 넘치는 부분은 오타로 본다.
- 전체 글자 수: 정답 문장들의 글자 수 합계 (입력 길이가 아님).
- 기록이 없으면(0문장) 정확도는 100%, 평균은 0으로 표시한다.

## 4. 랭킹

| 항목 | 내용 |
|---|---|
| 기록 조건 | 정확도 ≥ `MIN_ACCURACY`(95) |
| 파일 | `ranking.txt` (UTF-8), 한 줄에 `이름,정확도,평균WPM,최고WPM`, 소수 둘째 자리 반올림 |
| 이름 처리 | 이름 안의 쉼표(`,`)는 공백으로 바꿔 저장 |
| 저장 방식 | 파일 맨 뒤에 덧붙임 (파일이 없으면 자동 생성) |
| 정렬 | 정확도 ↓ → 평균 WPM ↓ → 최고 WPM ↓ (버블 정렬 직접 구현) |
| 표시 | 상위 `TOP`(5)명, 1등에는 `★` 표시, 기록이 없으면 안내 문구 |
| 주의 | 파일 위치는 **실행한 폴더** 기준이다. 게임 폴더 안에서 실행해야 한다 |
| 초기화 | `ranking.txt`를 지운다 |

## 5. 입력 처리

| 위치 | 입력 | 처리 |
|---|---|---|
| 메인 메뉴 | `s` / `r` / `q` (대소문자 무관) | 해당 동작. 그 밖의 입력은 무시하고 메뉴를 다시 그림 |
| 이름 | 빈 문자열 | 다시 입력 |
| 문장 | 아무 글자 | 그대로 비교 (앞뒤 공백은 제거됨) |

## 6. 설정값 (`main.py` 맨 위)

| 이름 | 기본값 | 뜻 |
|---|---|---|
| `TEXT_FILE` | `"text.txt"` | 연습 문장 파일 |
| `RANK_FILE` | `"ranking.txt"` | 랭킹 파일 |
| `COUNT` | 10 | 한 번에 테스트할 문장 수 |
| `MIN_ACCURACY` | 95 | 랭킹 기록 최소 정확도 |
| `TOP` | 5 | 랭킹에 보여줄 인원 |
| `WIDTH` | 62 | 가운데 정렬 기준 폭 |

## 6-1. 화면 폭 계산

한글(`가`~`힣`)은 2칸, 그 밖의 글자는 1칸으로 계산해 가운데 정렬과 표 줄맞춤을 한다. (`width`, `pad_right`, `pad_left`, `center`, `center_block`)

## 7. 주요 함수

| 구역 | 함수 | 역할 |
|---|---|---|
| 화면 출력 | `clear`, `ask`, `width`, `pad_right`, `pad_left`, `margin`, `center`, `center_block`, `show_title` | 화면 지우기, 입력 칸, 정렬, 타이틀 |
| 기록 계산 | `average`, `accuracy`, `show_status` | 평균, 정확도, 점수판 |
| 랭킹 | `load_records`, `save_record`, `is_higher`, `show_ranking` | 파일 읽기/쓰기, 순위 비교, 표 |
| 게임 | `intro`, `typing_test` | 안내와 이름 입력, 10문장 진행과 결과 |

## 8. 파일

|---|---|

| `text.txt` | 연습 문장 (한 줄에 한 문장, UTF-8) |
| `ranking.txt` | 랭킹 기록 (실행 중 자동 생성, git에 올리지 않음) |

| `README.md`, `SPEC.md` | 사용 설명, 명세 |

## 9. 제약과 알려진 사항

- Windows 전용: 화면 지우기에 `cls`를 쓴다. (macOS/Linux는 `clear`로 변경)
- 입력 중 Ctrl+C나 입력 종료(EOF)는 별도로 처리하지 않는다.
- 한글을 입력해도 오류 없이 글자 단위로 비교한다.
